# SmartBus Real-Time MongoDB & Socket.io Backend Server

Ushbu backend server SmartBus Flutter ilovasi uchun **MongoDB Atlas** ma'lumotlar bazasi va **Socket.io** orqali real-time avtobus koordinatalarini hamda SOS signallarini uzatib beradi.

## Ishga tushirish (Run Server):

1. **Terminalda backend papkasiga o'ting**:
   ```bash
   cd smartbus_backend
   ```

2. **Kutubxonalarni o'rnatish** (bajarilgan):
   ```bash
   npm install
   ```

3. **Serverni ishga tushirish**:
   ```bash
   npm start
   ```
   yoki kuzatuv rejasi bilan:
   ```bash
   npm run dev
   ```

4. **Port**: Server `http://localhost:4000` manzilida ishlaydi.
   MongoDB Atlas klasteringiz: `Cluster0` (smartbus).
